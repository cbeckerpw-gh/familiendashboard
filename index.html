📖 Entwickler-Dokumentation ("Lissmich")

Willkommen zur Entwickler-Dokumentation der Familiensteuereinheit. Dieses Dashboard ist hochdynamisch und modular aufgebaut.

1. Farbzuordnung & Kinderfreundlichkeit

Jeder Termin erhält basierend auf Keywords im Titel automatisch das passende Personensymbol und die dazugehörige Farbe:

  • Oskar (Grün): Titel enthält "Oskar"
  • Irma (Blau): Titel enthält "Irma"
  • Mama (Violett): Titel enthält "Mama"
  • Papa (Türkis): Titel enthält "Papa" oder "Christian"

Beim Antippen einer Terminkarte nutzt die Anwendung die Web Speech API, um den Termin auf Deutsch vorzulesen.

2. Google Kalender Anbindung (iCal / Google Calendar)

Um deine echten Kalenderdaten einzubinden, nutze eine Serverless-Funktion oder wandle deine iCal-Links per JavaScript (ical.js) um:

// Beispiel: iCal Feed abrufen und parsen
fetch('DEINE_GOOGLE_ICAL_URL')
  .then(res => res.text())
  .then(csvData => {
    // Parser-Logik zum Einfügen in das Dashboard
  });

3. Sungrow Wechselrichter (Modbus TCP & iSolarCloud API)

Die Live-Daten deines Sungrow-Systems (Erzeugung, Speicher-SoC) können über zwei Wege bezogen werden:

  • Modbus TCP (Lokales Netzwerk): Direktes Abfragen des WiNet-S-Sticks über Port 502 via Node-RED oder Home Assistant Proxy.
  • iSolarCloud REST API: Abfrage der OpenAPI von Sungrow für Erzeugung und Batteriezustand.

4. Zappi Wallbox Integration (myenergi API)

Die Zappi Wallbox stellt eine offene HTTP-Schnittstelle bereit:

// Abfrage des Zappi Lade-Status
fetch('https://s18.myenergi.net/cgi-jstatus-Z', {
  headers: { 'Authorization': 'Digest ...' }
})
.then(res => res.json())
.then(data => console.log(data));

5. Shelly Relais (Kinderzimmer-Licht)

Die Shellys im Kinderzimmer werden per lokaler REST-API abgefragt:

// Abfrage Shelly Status
fetch('http://192.168.178.XX/rpc/Shelly.GetStatus')
  .then(res => res.json())
  .then(data => {
    const isOn = data['switch:0'].output;
    const power = data['switch:0'].apower;
  });
